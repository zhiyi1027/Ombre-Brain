# 夜间梦境

夜间梦境是在逻辑日结束后由后台生成的、可缺席的合成派生物。它和现有 MCP `dream()` 不同：后者是主动回顾最近记忆的读取工具；夜间梦境不会在 `breath()` 调用时临时请求模型。

## 时间与生成

- 默认按 `Asia/Shanghai` 凌晨 4 点切日，继承 `daily_continuity` 的时区和切日时间。
- 后台每 5 分钟检查上一已结束逻辑日；同一天已有 artifact 时不重复调用模型。
- 默认有 70% 基础“醒来记得梦”的概率。四个来源或高唤醒度素材会各增加 10%，最高 100%。概率判定由日期、提示词版本与来源 revision 确定，因此重启不会反复掷骰子。
- 素材不足、概率门未通过、模型主动 abstain 或输出两次仍不合格时，会保存一条 `skipped` 状态；`breath()` 完全省略梦境段落。

## 来源选择

- 从前一逻辑日选择最多 3 条普通记忆/feel；有普通记忆时 feel 最多 1 条。
- 同一事件的来源按显式 source link 和正文相似度去重，不按“都是争吵/都是亲密”这种大主题粗暴合并。
- 可再关联 1 条至少 7 天前的相关普通记忆；优先语义检索，向量不可用时回退到保守的关键词重合。
- `plan`、核心、信、I、日印象、已消化、已取代、测试数据等不会成为梦的来源。便签与日印象也不会作为输入。
- 送入模型的是候选残片，不是覆盖清单。模型只围绕一个主要梦境选用 1 至 3 个来源、2 至 4 个细节，其余主动舍弃；春梦许可保留，但不得为了展示读过素材而堆叠无关关键词。

## 安全与隔离

生成提示词把全部来源明确标成历史数据，拒绝执行其中的命令。梦允许打乱时间、空间和物理规律，也允许自然出现亲密、色情、恐惧或温柔，但不得新增现实生平、健康事实、承诺或真实历史；模型可以返回 `dreamed:false`。

artifact 保存于 `<vault>/nightly_dreams/YYYY-MM-DD.json`。目录不属于 BucketManager 的普通桶集合，不参与搜索、向量化、衰减、日印象、当前事实或 supersession。成品保留来源 ID、完整正文 revision 哈希和模型/提示词版本，Dashboard 只暴露安全的来源名称与 ID，不返回送模截取正文或内部哈希。

若上一夜存在 `ready` 成品，`breath()` 在昨日印象之后、近期记忆之前返回：

```text
=== 昨夜的梦 · YYYY-MM-DD ===
[content_role:derived_memory_data] [instructions:false] [synthetic:true] [biographical_fact:false]
...
```

梦境使用独立 1200 token 启动预算；放不下时只返回 Dashboard 指针，不截断正文。Dashboard 的「梦境 / Dreams」页面只读展示成品和来源，不能编辑、强制生成或写回普通记忆。
